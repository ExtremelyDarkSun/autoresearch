# 新电脑恢复

目标是让新电脑恢复已维护的实验框架行为，并沿用原有项目层级。公开模板不能代替旧机当前实现、实验记录和部署状态。恢复分为公开组件安装、旧实现私有备份、机器配置重建和现场行为验收。

完整操作步骤在[项目安装说明](<../project/INSTALL.md>)。本页只记录组件对应和证据，不复制另一份操作流程。

## 本次修正

| 原差距 | 本次处理 | 验证方式 |
|---|---|---|
| 根topics等目录偏离原组织 | 新分层工作区把专题、代码、环境、计划放回中文实验层。明确布局标记，旧工作区不自动搬迁 | 新机路径与真实init→provision→Workflow→reporting组合测试 |
| 台账只写一句尚未配置 | 补章节、字段、模板行、状态词、取证和更正规则。研究数据仍为空 | 检查实际模板与安装副本，不以占位行作为事实 |
| 子会话默认全keep与当前策略不同 | 提供显式四入口过滤策略，保留全局偏好。新机部署生成器显式选filter | 真Node生成配置及主/子会话现场捕获 |
| tick只有全局机器可用性 | 增加已登记专题process_status投影和默认targets-db。保留STATUS研究正文 | 两tick、缺库、缺表、重绑、无绑定和缺专题目录测试 |
| GitHub没有旧机当前工作树 | 通用recovery工具导出当前磁盘字节与SQLite快照，真实包只存本地 | dirty工作树、WAL、哈希、拒覆盖、非法路径等恢复测试 |
| 旧机绝对路径无法搬到新机 | prepare_new_machine按实际路径生成部署参数，不自动改宿主 | 实际分层工作区与五个插件入口联合测试 |

## 三种材料

| 材料 | 内容 | 存放与保密 |
|---|---|---|
| 公开框架 | 通用代码、五个插件、契约、角色、模板、安装工具、合成测试 | GitHub |
| 私有恢复包 | 旧项目当前代码和文档、专题、运行数据库，显式选择的附加材料。含未提交修改 | 本地ZIP，不得提交Git或公开 |
| 新电脑本机配置 | 凭据引用、DSH profile、任务、模型/数据/评测器版本、新会话绑定 | 新机私有目录，与公开源码分开 |

私有包按当前文件系统取件。每个SQLite各自一致，整棵工作树不提供跨文件事务。导出回执必须查skipped清单，不能把默认排除当成不再需要。Git历史包也可能带旧身份与历史内容，始终属于私有材料。

源数据库和公共运行库不是同一套schema。工具恢复旧实现和原目录，不偷偷把旧topics库转换成新库，也不替旧授权重新背书。新项目仍用空库初始化，已有工程仍按原实现运行。

## 行为基线

1. 主会话负责目标、设计、执行、科学判断和下一步。默认短独立子会话，不继承长聊天。
2. 方案审查使用独立新会话。审计聚焦问题目标、设计测量基本正确性、决定性历史限制。小修自查不占审计次数，机器参数和实际实现字节改变仍需复核。
3. 意图监控默认关闭。只有用户明确启用才恢复监控义务。旧账保留，默认不阻断执行。
4. 开始推进专题时建立TOPIC、EVIDENCE、STATUS。事前事后留快照。STATUS八节只写研究内容，scribe必须实际派出，不能用空骨架通过验收。
5. 机器可用性和推进心跳留在process_status。页面mtime与心跳都不是实验存活证明。
6. 真实授权、预算、停止要求和执行真实性独立核验。无回复不是批准，复制旧记录也不是新会话授权。
7. 文档保持唯一正文、原编号、双向指针与可核字节。空数据保留格式，历史不充当现行规则。

当前全部109个预期编号及原顺序仍在[预期表](<../kernel/contracts/framework_expectations.md>)。编号对应不等于所有外部行为现场通过。[功能验收表](<EXPECTATIONS_ACCEPTANCE.md>)继续保留其能力边界。

## 需要在新电脑现场完成

2026-11-09旧机宿主审计读到的当次基线是：子会话入口过滤启用，doc-gap未挂载，AutoDL事件启用且无绑定hold，`compaction-basic`的`auto: true`。源工程旧安装说明中关闭自动压缩、启用doc-gap的内容已经落后于实际配置。恢复时按实际基线重建并核加载日志。公开参数生成器处理五个项目插件，不替宿主安装或修改自动压缩设置。

| 现场项 | 必须留下的证据 |
|---|---|
| DSH及插件版本 | 实际版本、apply日志、新宿主pid和真实输入捕获 |
| 指令完整性 | 对应任务全部必读文档已收到的证据，不能只报布局检查通过 |
| 代码与依赖 | 恢复清单、Git版本、脏修改、解释器、实际包、模型和题单指纹 |
| 定时任务 | 新路径下实际任务定义、连续两tick、专题状态与事件绑定 |
| 执行与停止 | 新机真实样例结果、退出码、停止证明、费用与资源状态 |
| 外部服务 | 凭据新配置、可信用户事件、真实送达和平台回读 |

源框架逐行读取覆盖的完整宿主闸仍未迁入公共引擎。私有包保留源实现，公开版保留此缺口。真实云机、飞书、SSH/POSIX停止、正式评测与线上提交必须现场验收。不能把本轮离线通过写成新电脑已经百分百恢复。
