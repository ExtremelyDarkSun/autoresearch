# 实验工具

比赛专属的安装、评测、打包、取回工具放本目录。**调用公共研究主链，不另建预算或授权账本**。

## 0 调用约定

- **一律从仓库根调用**：脚本靠自身位置反推仓库根，进了子目录就失效。
- **先看 `-h`/`--help`**：参数与默认值以脚本自述为准，本文件不复述会漂的默认值。
- **失败要能区分三类**：参数错（退出码 2 一类）/ 前置条件不满足（硬失败）/ 执行中失败。⛔ 不要都用同一个非零码。

## 3 验证记录怎么写

每个工具至少要过三项，并把**命令与逐字结果**记进 §2 的最后一列（或另起 `VERIFY_<工具>.md`）：

| 项 | 判据 |
|---|---|
| 正向 | 正常输入 ⇒ 退出码 0，且产出与期望逐条对得上（⛔ 只看「跑完了」） |
| 反向 | 缺参数 / 前置条件不满足 ⇒ 非零退出码 + 可操作提示，且**没有留下半成品** |
| 幂等或可重跑 | 重复跑同一输入 ⇒ 结果一致，或明确拒绝并说明原因 |

⚠️ **只测过 `--help` 不算验证**；⛔ 把「本机自检通过」写成「已验证可用」。
