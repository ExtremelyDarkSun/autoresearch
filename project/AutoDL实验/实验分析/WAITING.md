# 等待簿 —— 现在挂着没动的事

> **这是什么**：一张**挂起清单**。凡是要「等一个人答话」「等某一轮出数」「等机器与额度」才能继续的活，都登记在这里，**不再各自开一份「设计」文档**。
> **这不是台账**：它不记结论、不记读数、不判假设。科学内容仍在专题 `TOPIC.md` 的假设台账、`plans/<实验号>.json` 的事前设计与 `EVIDENCE_<日期>.md` 的原始证据。
> **谁看**：人扫一眼就知道「现在卡在哪、要谁答什么」；AI 每轮起跑前扫一遍，把已有答案的条目解掉、把等不到的作废。

## 0 怎么用（三条，够用就行）

1. **起跑任何实验之前扫一遍本页**：有没有一条已经满足了、可以落了？有没有一条等的正是这次要跑的实验？
2. **解掉的就删行**，不留「已完成」的历史 —— 这里的价值只在「现在还挂着什么」。要查历史，证据在 `EVIDENCE_*.md` 与实验运行登记。
3. **超过 3 天没动过的条目必须复核**：要么重排优先级，要么标 `作废`。复核从条目 heading 的 `登记：` 日期算（改了等的东西就同时改这一格）。⛔ 不许无声挂在那里变成僵尸条目。（3 天是默认复核线；项目要改就改这一行，⛔ 不另开一份规则。）

## 1 条目格式（每条 4 行，不写正文）

```
### W<n> · <一句话是什么>　状态：<等审批 / 等读数 / 等机器 / 作废>　登记：<YYYY-MM-DD>
- 在等什么：
- 等到了立刻做什么：
- 起跑前必须满足：
- 设计细节在哪：
```

- 一条只回答「在等什么 · 等到了做什么 · 起跑前必须满足什么 · 细节在哪」这四行；**判据正文、读数、结论都不抄进来**（第 4 行只放指针）。
- `W<n>` 只增不复用；作废的条目先标 `作废` 并写一行原因，确认不再需要后按 §0 第 2 条删行。
- 状态只取四档：`等审批` / `等读数` / `等机器` / `作废`；等的东西换了就改这一行，⛔ 不留两种说法。

## 2 唯一出处（硬规则）

等待期设计**只落在这里**：

- 专题目录（`topics/<专题>/`）的**直接层不许出现 `DESIGN_*` 条目**（文件或目录都算）；该专题 `archive/` 里的历史件不追溯、不判红。
- 需要写设计细节时，写进该专题 `TOPIC.md` 的对应节或 `plans/<实验号>.json`，本页第 4 行只放指针。
- 退役件进该专题的 `archive/`，按维护契约留索引；⛔ 不把「设计」文件平铺在专题目录里当第二落点。

程序判据（只读，不建不改文件）：

```powershell
python -X utf8 -B research.py workspace documents --workspace <工作区> --topic <专题> --check
```

专题直接层出现 `DESIGN_*` ⇒ 判红（退出码 2），消息里点名条目与本节落点；子目录与 `archive/` 里的历史件不计入。

## 4 过期复核

| 情形 | 复核什么 | 动作 |
|---|---|---|
| 超过 3 天没动（从 heading 的 `登记：` 算） | 还在等同一件事吗？ | 重排优先级，或标 `作废` 并写明原因 |
| 等的前置已经不成立 | 那条读数 / 那台机器 / 那个决定还有效吗？ | 直接删行；要查历史去证据与运行登记 |
| 等的事其实已经能做 | 有没有别人已经答了、条件已满足？ | 立刻落地，条目删行 |

> 复核是纪律，不是闸：没人写不会自动报错。所以每条在新增时就写清「在等什么」，让复核只判一件事 —— 这个前置还成立吗。
