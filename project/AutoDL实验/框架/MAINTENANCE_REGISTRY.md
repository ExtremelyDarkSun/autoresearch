# 文档维护登记

> 本文件只回答一件事：**哪些文档该分层、按什么切、滚到哪一步**。它不改任何文档的判据。
> **默认限额与滚动正文只在[维护契约](../../../kernel/contracts/doc_maintenance.md)**，本表不复制数字（口径变了改一处）。
> 什么时候读：新建一份会被反复追加的文档之前 · 发现某份文档大到不敢读之前 · 做完一轮想往里追加之前。

---

## 0 判据：一份文档该不该分层

前两条都满足才做，第三条决定切法。

| # | 判据 | 怎么测 |
|---|---|---|
| **J1** | 它每轮 / 每次都**被通读**吗？ | 问：最近三次动它，是不是都得从头读一遍？是 ⇒ 候选 |
| **J2** | 它有明确的「结案」状态吗？（已解决 / 已收工 / 已作废） | 有 ⇒ 按状态切；没有 ⇒ 只能按时间切（只留最近若干天在热件） |
| **J3** | 它的增长是「追加新条目」还是「反复改旧条目」？ | 追加为主 ⇒ 时间切片成立；反复改旧条目 ⇒ 先加状态列，再切 |

**⛔ 不该分层的情形（别乱切）**

- **索引类**（入口文件、`*_INDEX.md`、路径对照表）：价值就在**一处看全**，切了就没用。
- **一次性报告**（分析文档、复盘）：写完就不动，它不是「经常需要编辑」。
- **规则 / 契约正文**：J2 要的「结案态」在规则上不存在 ⇒ 冷热切法没有落点。⚠️ 但它**可以切**，只是换切法，见 §1。
- **读取入口本身就很少**的件（例如只被某条闸引用）。

## 1 两种切法（⛔ 不要混用）

| | 台账（未结案 / 已结案那一类） | 规则 / 契约正文 |
|---|---|---|
| 切分维度 | **状态** + **时间** | **触发条件**（「你正要做什么」→ 读哪一节） |
| 冷热怎么分 | 热 = 未结案；冷 = 已结案按天 | 没有冷热，切成「入口表 + 若干按任务分的节」 |
| 硬约束 | 冷件逐字不动、编号不重用 | 每节只有一份，⛔ 不切「精简副本」；入口表必须把「做什么 → 读哪节」写死 |

⚠️ ⛔ **不许为了变小而删内容**：滚动是**搬运 + 留痕**，删除是另一件事（要单独授权）。
⚠️ **披露不豁免完整读**：分层只决定「先看哪一层」，与任务相关的现行规则 / 方案 / 分析文档仍须**整份读完**。

## 2 分层怎么摆（默认形态）

```
<热件>.md              ← 只有「未结案」条目，受契约里的上限约束
<热件>_cold/           ← 已结案，按天切片
   ├─ INDEX.md         ← 唯一入口：编号 → 冷件文件名
   ├─ <YYYY-MM-DD>.md  ← 当天滚出来的所有节（逐字原文）
   └─ ...
```

**落点**：冷目录是热件的**同级子目录**，⛔ 不新建根级目录（相对链接因此稳定，跟着热件一起搬家）。
**命名**：`YYYY-MM-DD.md`；同日第二次滚动 ⇒ 追加到同一份并加小标题。
**冷件不进 `archive/`**：归档的语义是「不用了但要留痕」，冷件还在被引用。

热件切完之后顶部必须有指针块：已滚出哪些编号区间、索引在哪、本文件只保留什么（双向指针的口径见维护契约）。

## 4 一次滚动的照抄步骤

> 顺序不许换；第 1 步与第 8 步是最容易出事的两处。

1. **确认没有别的写者**（看工作区状态与最近修改时间；台账会自述谁在写）⇒ 有写者就停。
2. **记滚动前可核值**：字节数 + 指纹。
3. **逐个列出要滚的节**（节号区间 + 每条的结案判据），⛔ 不许写「大概前面的都滚」。
4. **把逐字原文复制进冷件**（同日第二次滚动就追加）；复制后抽几处对字节。
5. **冷件顶部写四样**：来源热件 · 覆盖编号区间 · 滚动时刻 · 滚动前热件指纹。
6. **更新冷件索引**：编号 → 文件名，一行一条。
7. **从热件删掉那些节**，并在顶部写指针块。
8. **复算热件字节与指纹**，与第 2 步对照；差值应 ≈ 滚出节字节之和，对不上就停下查。
9. **跑一遍全局链接/结构校验**，并把结果写进收工报告。

## 5 闸与「仍是纪律」

**闸**：文档体量校验（读一份清单，逐个量，超硬上限 ⇒ 报错并点名；带离线自检与一组**故意做坏**的用例）。
⚠️ 这道闸在本仓库**是否已存在要以实际文件为准**；⛔ 本文件不假装它存在。

**仍是纪律**（收工报告必须显式写出哪几条本轮没做）：

1. **「到线了就去滚」这个动作本身** —— 脚本能报「超了」，替不了你去滚。
2. **「哪些条目算已结案」这个判断** —— 脚本判不了这条是不是真的修好了。
3. **「索引写对没有」** —— 闸能查「指向的编号在不在」，查不了「这个编号该不该归到这一天」。
4. **把本规则接进每一轮流程那一下**。
