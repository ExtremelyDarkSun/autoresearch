# REQUESTS 冷件 · 索引

> **本文件是冷件唯一的入口。** 热件 = [`../REQUESTS.md`](<../REQUESTS.md>)。
> ⚠️ **没有本索引的冷件等于丢失** —— 你会知道「它被滚走了」，但不知道该读哪一天。
> ⚠️ **读法不变**：按编号查状态，**以「最后一次提到它的那一节」为准**；用 §2 的反查表定位那一节。
> ⚠️ 本文件只做指路，**不复制条文、不判断状态**。

## 4 冷件本身怎么写

每份冷件顶部必须写四样，缺一样就不可追溯：

1. **来源热件路径**（从哪份文件滚来）。
2. **覆盖的编号区间**（含首尾）。
3. **滚动时刻**（带时区）。
4. **滚动前热件指纹**（字节数 + sha256）。

⚠️ 同一天滚两次 ⇒ 追加到同一份，并在冷件内加「第 N 次滚动（HH:MM）」小标题；⛔ 不建第二份同日文件。
⚠️ 冷件**不进 `archive/`**：它还在被索引与结论引用；整份热件彻底退休时才进归档。
⚠️ 冷件正文**逐字不改**；发现写错了在热件里加更正并指回冷件行号。
