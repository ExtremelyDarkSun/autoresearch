# 实验记录入口

查东西从 §0 这张表开始；找不到再去 `archive/` 或版本库历史。
本目录按「活件 / 历史」两层摆放，旧路径换算见 §4。

## 1 目录怎么摆

判据只有一条：**写完以后还会不会被改。**

```
实验记录/
├─ README.md                   ← 本文件（唯一入口）
│
├─ 活件（还会被改，留在本层）
│  ├─ EXPERIMENT_RULES.md      规则的唯一住所
│  ├─ EXPERIMENT_STATUS.md     逐实验台账
│  ├─ BASELINES.md             基线名单 + worktree 台账
│  ├─ EXPERIMENT_LOG.md        append-only 工作日志
│  ├─ AUTODL_SETUP.md          环境手册
│  └─ PARALLEL_AND_COST.md     并行与成本判据
│
└─ 历史/                       写完不再改的（交接单、一次性登记、旧预注册）
   ├─ INDEX.md                 清单 + 反查
   └─ <日期或编号>.md          按日期保存，原编号不重用
```

证据本体（逐题读数、审计、快照）不在本目录，落在 `实验分析/` 与各实验的 `state/`；本目录只放**索引与判据**，不复制会漂的数。

## 2 活件与历史的分界

判据仍是「写完还会不会被改」：仍在维护的规则、台账、手册留本层；一次性交接单、完成后不再改的登记与旧预注册进 `历史/`。
这是整份文档的活/历史分界，**不等于**维护契约里的单条热/冷滚动 —— 仍需按编号引用的冷件不能当无用归档。

⛔ 不要放进 `历史/`：仍在被反复改的台账（`EXPERIMENT_STATUS.md` / `BASELINES.md` / `EXPERIMENT_LOG.md`）、规则正文、下一轮还要照着做的手册。一放进去，「整体归档」这个动作就失效了。

## 3 清空实验历史（以后要做时）

「清空实验历史」= **把 `历史/` 整体归档**，一个动作，不是逐文件挑。⛔ 不直接删除；归档不用问，删除要单独授权。

顺序不许换：

1. **先核引用**：读 §4 的表 + `历史/INDEX.md` 的「仍被谁引用」列，列出会断的链接。
2. **确认没有别的写者**：本目录的台账会自述谁在写；有写者就停。
3. **整体归档**：把目录移进 `archive/`，保留原名并带日期；再建一个空 `历史/` 继续积累。
4. **改活文件的引用**：把仍在维护的文件里的旧路径改到归档位置。
5. **在日志末尾追加一节**说明搬去了哪（append-only：只加不改）。

⚠️ 有三类引用归档后**接受它们断**、不要去回改：`EXPERIMENT_LOG.md`、`EXPERIMENT_STATUS.md` 与 `框架/REQUESTS.md` 里的旧路径，它们是**历史陈述**，指向当时的位置。
⚠️ 实际状态库与运行产物另有工具依赖，不能因为整理文档就一起挪动。

## 4 旧路径换算

尚无迁移记录。新增一行时必须写全五列；同一批搬迁记在一行，不要只写「大概前面的都搬了」。

| 原位置 | 现位置 | 搬迁时间 | 指纹（字节 · sha256） | 仍保留旧写法的历史件 |
|---|---|---|---|---|
| `<实验记录/旧名.md>`（占位示例，非实例） | `<实验记录/历史/旧名.md>`（占位示例） | `<YYYY-MM-DD HH:MM>` | `<字节数> · <sha256>` | `<文件名与处数>`，无则写「无」 |

换算规则默认「文件名一个字节不改，只换所在层」；改名的搬迁必须在表里写明原名与新名的对应。

## 5 维护时机

| 时机 | 做什么 |
|---|---|
| 每轮收工 | 日志末尾加一节；台账加行；§4 有新搬迁就加一行 |
| 冻结或新增基线 | 只改 `BASELINES.md`，本文件不动 |
| 目录结构变了 | 同时改 §1 目录树与 §4 换算表，并核所有链接 |
| 整份历史归档 | 走 §3 的五步，改完在日志里留一节 |
