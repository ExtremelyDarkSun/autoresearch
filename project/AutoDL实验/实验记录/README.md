## 活件与历史

判据是写完以后还会不会改。仍在维护的手册、规则、状态入口留本层；一次性交接单、旧预注册和完成后不再改的文档进历史目录。
这是整份文档的活/历史分界，不等于维护契约中的单条热/冷滚动。仍需按编号引用的冷件不能当无用归档。

未来整体归档历史时先核引用和其他写者，保留原件及替代位置，再重建空历史入口。删除仍需授权。
活文件链接同步到新位置；append-only历史陈述不回改，在下面旧→新表登记换算。实际状态库和运行产物另有工具依赖，不能因整理文档一起挪动。

## 旧路径换算

尚无迁移记录。新增时记录原位置、现位置、搬迁时间、指纹及仍保留旧写法的历史件。
