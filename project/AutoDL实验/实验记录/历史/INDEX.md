# 工作与运行历史

> 本目录是「实验历史」的**物理边界**：里面全是**写完就不再改**的交接单、一次性登记与旧预注册。

## 2 清空前必须做的三件

1. **先做一次历史清除的案例复盘**：把上次搬动的口径、体量、版本库兜底覆盖率、校验闸会不会因此报红、踩过的坑读一遍；没有旧案例就先写一份本文档（记清搬了什么、断在哪）。
2. **按 §1「仍被谁引用」逐个改活文件里的引用**。只有这一列是活文件；`EXPERIMENT_LOG.md`、`EXPERIMENT_STATUS.md`、`框架/REQUESTS.md` 里的旧路径**有意不回改**（它们是历史陈述）。
3. **归档之后在[工作日志](<../EXPERIMENT_LOG.md>)末尾追加一节**说明搬去了哪（append-only：只加不改）。

⚠️ 同时确认三件事：没有别的写者在写这批文件；搬动前后的字节数与指纹已记；程序是否依赖这些路径（依赖就不能搬）。
