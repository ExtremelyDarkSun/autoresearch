## 一节的硬要求

| 项 | 要求 |
|---|---|
| 预期与开机顺序 | 预期段**写在开机之前**；做不到（例如接机自检必须先开机）要在本节明写偏差、影响评估，并保证本段**不引用本轮读数** |
| 唯一变量 | 三轮改动混在一轮 ⇒ 直接写「无法分别归因」，⛔ 不许事后挑一个说成因果 |
| 判据 | 每条预期都要有**可观测**的取数方式（哪个文件、哪个过滤条件、几行）；「感觉更好」不算判据 |
| 对账 | 收工时逐条回填「预期 vs 实际」，未达成的也留着；⛔ 不许删掉没达成的预期 |
| 数字 | 【实测】数字写明出处与取数方式；【推断】写算式；未取回就写「未取回」，⛔ 不许估一个填上 |
| 边界 | 写清「本轮**不能**回答什么」（单臂、样本小、装置不同源等），避免下一轮把并列当因果 |
