# 项目组织抽取映射

本模板保留已维护的组织行为，不复制特定比赛的事实或旧会话状态。核对过的来源版本留在[来源指纹](<organization-source-manifest.json>)；只记录标签、字节和哈希，不包含原实例内容。指纹不是完整迁移证明。

维护史中已出现的故障也作为组织依据：根入口移成第二跳后，新会话看不到必读材料；正文与索引数量曾漂移；实验记录曾因历史与活件混放难以交接。模板分别保留开局直接指针、非固定数量导航和[记录分层入口](<AutoDL实验/实验记录/README.md>)。

| 原组织能力 | 随仓库提供的落点 | 保留或适配 |
|---|---|---|
| 根索引、共同规则、平台线、实验线、框架子项目 | 根及三层 AGENTS | 保留层级、触发范围与开局直接指针 |
| 文件分类与层级约束 | RULES §1.1、§1.7 | 临时件/分析/原始资料/运行态各有住所；新增根目录要理由 |
| 文件头、实际改前件与归档 | RULES §1.2、维护契约 | 保留五要素、工作树优先、双向替代与可核字节 |
| 当前答案、行动依据、历史、原始证据 | 维护契约 | 保留四层及原始证据，不以摘要豁免现行全文读取 |
| 热件与每日冷件、编号反查 | 维护契约、各冷件 INDEX | 保留结案判据、同日追加、编号不重排及上限口径 |
| 现行规则只一份、索引一跳直达 | 根索引与各层入口 | 索引引用内核唯一正文；安装时复制同版本，链接改到本地 |
| 机读读取与人读表同步 | 框架/context_routes.json、CONTEXT_LOADING | 组织路由与内核 reading_required 分开：前者选入口，后者定义执行必读义务 |
| 基线不等于中间实验与当前提交包 | BASELINES、EXPERIMENT_STATUS | 语义保留，名单与结果为空 |
| 实验前后快照与人读/机器材料分开 | topics、.autoresearch、实验分析索引 | 为兼容公共工具，专题正文固定在根 topics；原中文层保留索引，不再复制正文 |
| 目录迁移与旧节号追溯 | 本映射与历史 INDEX | 不搬入旧比赛的整套变更史，项目未来迁移须登记旧→新 |
| 真实宿主分层注入与子会话精简 | 安装说明与读取政策 | 源码/模板存在不等于宿主加载；必须实际探针 |
| 用户最近减少流程的决定 | RULES §1.3、加载图的兼容边界 | 不以旧归档恢复撤销义务；涉及执行闸的运行差异必须单列，不能靠模板冒充代码已同步 |

## 内容边界

复用的内容：上述目录、规则、空台账、索引、加载图、维护清单、专题文档样式与来源指纹。
另行配置：比赛地址与官方材料、目标代码、评测适配、预算、凭据引用、真实实例。
不伪造：旧实验、旧认可基线、旧用户授权、活跃任务、可信宿主证明。
当前模板默认保留公共工具的执行约束。原项目最新流程政策与执行引擎的逐项差异见[加载图兼容边界](<AutoDL实验/框架/CONTEXT_LOADING.md#执行兼容边界>)，不能用组织验收代替行为迁移验收。
