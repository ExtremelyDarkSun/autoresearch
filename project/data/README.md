# 原始数据

本目录是**原始数据的固定落点**。原始数据**只读**：任何清洗、切片、转换都落派生目录，⛔ 不覆盖原件。
凭据不入版本库；工具管理的目录不手工伪造运行状态。

## 1 数据清单

> 一行 = 一个数据对象（一个文件，或一个可独立校验的目录）。第 1 行是**模板行**（尖括号内为占位），⛔ 不得当真实数据读。

| 数据 | 来源（URL / 平台对象） | 取得时间 | 字节 | sha256 | 原件路径 | 派生件 | 可否引用 | 状态 |
|---|---|---|---|---|---|---|---|---|
| `<名称>`（占位示例） | `<URL 或平台资源标识>` | `<YYYY-MM-DD HH:MM>` | `<n>` | `<sha256>` | `data/<路径>` | `<派生出什么>`，无则「无」 | `<可引 / 仅内部使用 / 不得引用>` | `<只读 / 只读且已核 / 待补>` |

**条目约定**

- **一件一行**；目录类对象写「目录 · 文件数」并在旁边给出逐文件指纹清单的位置。
- **`sha256` 必填**：大文件用官方给出的校验值或自己算一次；⛔ 写「未知」之外的模糊值。
- **「可否引用」两档**：`可引`（已核且知道适用条件）/ `不得引用`（来源不明、版本不明或缺失件）。

## 2 目录约定

| 子目录 | 装什么 | 只读 | 备注 |
|---|---|---|---|
| `tasks*` | 题面清单（一行一题） | ✅ | 逐题字段先 probe 再用，⛔ 不按想象定字段 |
| `sandbox/` | 每题运行所需的仓库快照 | ✅ | 与题面清单按题号对得上 |
| `whl/`、`wheels/` | 依赖轮子 | ✅ | 少一个就会被守卫拦下 |
| `snapshots/` | 逐题快照包 | ✅ | 只传要跑的题 |
| `graphs/`、`embeddings/` | 图与嵌入（按题命名） | ✅ | 按题精确挑，⛔ 不整包传 |
| `docker/`、镜像说明 | 评测沙箱的镜像与说明 | ✅ | 记录镜像标识，不记录凭据 |

## 3 三条纪律

1. **原件只读**：`data/` 里的文件⛔ 不被任何脚本就地改写；要改就复制到 `temp/` 或派生目录。
2. **不在本目录放凭据**：token、cookie、口令⛔ 不入库；需要引用时只写「凭据的私有位置」。
3. **不手工伪造状态**：工具运行的产物由工具写；⛔ 手写状态文件冒充「跑过了」。
