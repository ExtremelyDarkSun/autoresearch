# acme-pipeline 项目入口

> 本文件是**索引**：只写「该做什么」和「东西在哪」。论证、数据与历史都在被指向的文件里，本文件不复述。

## 这份文档是什么

项目唯一入口。读者：新开会话的主负责人。时机：开局第一屏，以及不确定「这件事该读哪份」时。

## 三类内容与直接入口

| 要做什么 | 直接读哪里 | 何时读 |
|---|---|---|
| 放文件、建目录、留改前证据 | `RULES.md` | 动手写任何文件之前 |
| 改一个清洗步骤的逻辑 | `pipeline/AGENTS.md` | 动 `pipeline/` 下任何文件之前 |
| 查上游数据源的口径 | `docs/SOURCES.md` | 引用任何外部数字之前 |
| 查「这批数据当时是怎么跑的」 | `runs/INDEX.md` | 比较两次运行之前 |
| 判「这一轮算不算成功」 | `EXPECTATIONS.md` | 开跑前 + 收工前 |

## 上下文边界

- `archive/` 里的旧入口**不生效**，一律以本文件与现行分册为准
- 结论、版本、机器名、当前进度**不写进入口**，写进各自的台账
- 子 agent 默认是独立新会话：只交接目标、文件范围与验收条件，不让它通读全部索引
