# 临时件

「只用一次」或「随时可以删」的东西放这里。⚠️ **本目录内容随时可能被清空** —— 只有一份的东西⛔ 不要放这里。

## 1 放什么

| 该放 | 例 |
|---|---|
| 候选稿、草稿 | 还没定稿的提示词、配置、方案 |
| 中间产物、调试输出 | 抓取中间件、比对结果、日志片段 |
| 一次性脚本 | 只跑一次的分析或修复脚本 |
| 试验性的数据切片 | 抽样清单、临时 JSON/CSV |

## 2 不放什么

| 不放 | 该去哪 |
|---|---|
| 要长期保留的东西 | 归档到 `../archive/` 或写进对应业务目录 |
| 会漂的实测数据与读数 | 台账与报告（`../AutoDL实验/实验记录/`） |
| 别人维护的文档副本 | ⛔ 不复制，直接引用原文件 |
| 凭据、token、cookie | ⛔ 永不入库，也不写进日志 |
| 原始数据、提交包 | `../data/`、`../submission/` 各有固定落点 |

## 3 一次性脚本登记

> 一行 = 一个一次性脚本。第 1 行是**模板行**（尖括号内为占位），⛔ 不得当真实脚本读。
> 「已固化到正式件」为空就必须写**为什么还不固化**，否则下一轮会再写一遍。

| 脚本 | 干什么 | 输入 | 输出 | 已固化到正式件 | 可否删除 |
|---|---|---|---|---|---|
| `<文件名>`（占位示例） | `<一句话>` | `<读哪些文件>` | `<写哪些文件>` | `<正式件路径 + 节号 / 空>` | `<可删 / 还需保留：原因>` |

## 4 命名与保留

- **命名带日期或用途**：`<YYYYMMDD>_<用途>.<ext>`，⛔ 用 `test1`、`new`、`final` 这类名字。
- **同一件事只留一份**：多版本用后缀区分（`_v2`），并在登记表里只登记在用的那份。
- **保留期**：一次性脚本跑完、结论进正式件之后即可删；脚本若解释了某个读数，先把它固化再删。

## 5 清理

清理属于**删除动作**：执行前先确认①没有别的会话在读；②目标路径是 `temp/` 下的具体项（⛔ 不是通配）；③清单里标「还需保留」的没被选中。
清完之后在本文件 §3 把对应行的「可否删除」改成「已删（日期）」，⛔ 不直接删行。
