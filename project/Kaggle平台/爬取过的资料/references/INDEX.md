# 参考备份

只收**与主要原件对应**的备份，标明重复关系，避免重复读取与重复统计。
⚠️ **备份不是第二份证据**：同一内容的两个副本只算一条证据。

## 1 备份登记表

> 一行 = 一个备份目录或文件。第 1 行是**模板行**（尖括号内为占位），⛔ 不得当真实备份读。

| 备份件 | 对应原件 | 重复关系 | 字节 | sha256 | 差异说明 | 可用性 |
|---|---|---|---|---|---|---|
| `<目录或文件名>`（占位示例） | `<../ref_kernels_all 等>` | `<完全重复 / 子集 / 多出 N 项>` | `<n>` | `<sha256 或「目录未逐文件核」>` | `<多/少哪些，逐字相同的判定方式>` | `<可用 / 只作对照 / 勿引用>` |

**「重复关系」三档写法**

| 档 | 判据 | 后果 |
|---|---|---|
| 完全重复 | 逐文件 hash 一致 | 只算一条证据 |
| 子集 | 数量少且每个都能在原件里找到 | 统计数量时⛔ 不重复计数 |
| 多出若干项 | 有原件里没有的条目 | 多出的条目必须单独登记到对应子索引，⛔ 不当作原件的一部分 |

## 2 使用规则

1. **先查重复再统计**：报「有多少篇/多少条」之前先做集合对照；重叠部分⛔ 不能相加。
2. **差异要写判据**：写清「逐字相同」是用什么方式比的（hash / 逐文件 diff / 只比文件名）。
3. **命名带来源**：备份目录名要能看出它备份的是谁；⛔ 用 `ref`、`old`、`bak` 这类无信息名。
4. **只作对照**：引用外部结论时指回**原件路径**，⛔ 不指备份路径。
