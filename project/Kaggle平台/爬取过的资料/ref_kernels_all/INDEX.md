## 1 逐篇登记表

| slug | 载体 · 体积 | 作者 | 来源（URL 与取得时间） | 一句话 | 标签 | 可复用产出 | 自称结果 | 分档 |
|---|---|---|---|---|---|---|---|---|
| `<owner__slug>`（占位示例） | `<ipynb / py / 空>` · `<n>` | `<作者>` | `<URL>` · `<YYYY-MM-DD>` | `<它做了什么>` | `<机制 / 数据 / 评测 / 调参>` | `<能直接抄的文件或做法>`，无则「无」 | `<作者自述数字>` | `必读 / 选读 / 跳过` |

**三条读法**

1. **先在本表按标签或一句话过滤**，得到候选 slug，⛔ 不要逐篇打开。
2. 看「可复用产出」列：没有可复用产出的，再热闹也不进必读。
3. 只对 `必读` 读速读版（纯 markdown 摘录），确有必要再开原文；`跳过` 的⛔ 不打开。

## 2 词与标记

| 载体 | 含义 |
|---|---|
| `ipynb` | 正常 notebook |
| `py` | 脚本型 kernel |
| `空 / 仅元数据` | 没有代码，**别去读** |

| 标记 | 含义 |
|---|---|
| `【他人自述·未验证】` | 作者自己写的数字或结论，只作线索 |
| `必读` | 有可直接复用的产出，或揭示了关键机制 |
| `选读` | 有局部价值 |
| `跳过` | 骨架 / EDA / 无结论 / 空 |

## 3 纪律

1. **重复不算多篇**：同一模板重发的多份，正文可能逐字相同；报「有多少篇参考」前先做逐字比对，⛔ 按目录数直接计数。
2. **速读版不是原文**：速读版只保留叙述部分，代码与输出不在里面；要照抄实现时回原文。
3. **空目录要标出来**：只有元数据或抓取失败的目录，在本表写「空」并给原因，⛔ 让下一轮白读一遍。
4. **版本**：同一 slug 多次抓取时保留旧目录，新行写「取代关系」。
