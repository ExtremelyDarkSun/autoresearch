# 平台工具

本目录放**与平台交互**的工具：抓取、取数、提交、取分、结构校验。
⚠️ **通用评测协议来自所选 profile，不代表官方环境已安装**；真实提交须**逐次明确批准**；只读获取也要遵守真实访问权限。

## 0 权限与凭据边界

| 规则 | 内容 |
|---|---|
| 只读优先 | 能用匿名只读接口拿到的，不登录、不写 |
| 写操作 | 提交、改配置、上传一律先有批准证据（用户原话 + 时间） |
| 默认空跑 | 提交类工具默认 dry-run，不带显式开关时**不得**真发请求 |
| 凭据 | 只记**解析顺序与文件位置**，⛔ 不记值；日志⛔ 不打明文 |
| 额度 | 提交前先查当日已用；查不到就拒绝真提交（⛔ 不「先试试」） |

## 2 六要素登记

> 六列缺一列就不算接入完成。第 1 行是**模板行**。

| 工具 | 入口（命令） | 输入 | 输出 | 副作用 | 依赖 | 验证记录 |
|---|---|---|---|---|---|---|
| `<文件名>`（占位示例） | `python <路径> <参数>` | `<读哪些文件 / 参数>` | `<打印什么 / 写哪些文件>` | `<联网、写远端、消耗额度：会 / 不会>` | `<Python、CLI 版本、第三方包>` | `<哪次验证 + 结果 + 落点>` |

**副作用必写三项**：是否联网 · 是否消耗额度 · 是否会写远端或本地状态。

## 3 退出码约定

| 码 | 含义 | 调用方该做什么 |
|---|---|---|
| 0 | 成功（或 dry-run 成功） | 继续 |
| 1 | 执行失败（前置条件不满足 / 校验不一致 / 被平台拒绝） | 停下看提示，⛔ 不重试到成功 |
| 2 | 参数缺失或非法 | 改参数，⛔ 不忽略 |
| 其它非零 | 工具自定语义 | 读工具自述，并在 §2 登记 |

⚠️ 后台作业可能把非零码压成 1 ⇒ 判断成败要读**落盘结果**，⛔ 只看退出码。

## 4 验证记录

| 项 | 判据 |
|---|---|
| 正向 | 正常输入 ⇒ 退出码 0，产出与期望逐条对上 |
| 反向 | 缺参数 / 无凭据 / 超额度 ⇒ 非零码 + 可操作提示，且**没有副作用** |
| 只读性 | 只读命令跑完，远端与本地状态**逐项不变**（用前后对照证明） |

⚠️ 只跑过 `--help` 不算验证；⛔ 「没报错」不等于「验证通过」。

## 5 绝不能做

1. ⛔ 打印或落盘凭据值（token、cookie、口令）。
2. ⛔ 无批准证据就提交；⛔ 把「上次批过」当本次授权。
3. ⛔ 用文本管道传递二进制内容再算指纹（会改字节，且不报错）。
4. ⛔ 在只读数据目录里写产物。
5. ⛔ 手工伪造工具的运行状态文件。
