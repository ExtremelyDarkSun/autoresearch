# 平台实验索引

> 一次平台提交**一节**，编号递增，旧节一字不改；本文件只记**发生了什么**，不记预测。
> ⛔ **本地结果不能填进平台结果栏**；没返回就写「未返回」，⛔ 不许估。
> 证据等级：`【官方】/【实测】/【读码】/【推断】/【未验证】`。

## 3 取证坑（复用时先读）

1. **用文本管道读版本库内容再算指纹会得到假值**：管道会做编码/换行转换，同一份内容能算出第三个 hash，且**不报错**。核对内容一律走二进制读取。
2. **平台侧没有运行时长字段**：想知道跑了多久只能按「接收时刻 → 出分时刻」的间隔读，⛔ 不要写成官方时长。
3. **「无分」有多种原因**：运行超时、异常、平台侧错误各有不同报文；引用时必须抄平台逐字，⛔ 不合并成一类。
4. **包指纹要在提交那一刻留**：事后从临时目录复原不算提交时证据；临时件会被覆盖。
5. **HASH 与最后一次写之间不许有别的写**：否则算出来的指纹与提交内容对不上。
