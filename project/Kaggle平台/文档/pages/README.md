# 页面原始数据

保存平台返回的**原始结构化数据**，一页一份，原样落盘。
没有原件时不能凭摘要补造；抽取值怀疑有误时**回这里复核**。

**完整性判据**（必须写一条，⛔ 不许只写「完整」）：

- 与接口返回的总数对齐（用返回里的计数字段校验），或
- 页面清单逐个对得上，或
- 写清缺哪几个、为什么缺（限流 / 需要认证 / 字段被裁）。

## 三条禁止

1. ⛔ **不覆盖原件**：要重抓就新建一份带时间戳的文件，旧的留作对照。
2. ⛔ **不在原件上做修改**：任何清洗、切片、改写都落 `../sections/` 或 `../text/`。
3. ⛔ **不把凭据写进 dump 或文件名**：只记接口方式与脚本路径，⛔ 不记 token 值。
