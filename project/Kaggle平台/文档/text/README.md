**转换纪律**

1. **同一原文只保留一种文本形态**：不要为同一页同时维护「去标签版」「去空白版」「分页版」多份 —— 多份必然漂，且没人说得清哪份是准的。
2. **转换必须可复跑**：写清脚本与参数；改了脚本就在表里加新行，⛔ 不覆盖旧行。
3. **编码与换行**：转换时固定编码与换行形态并写进表里；跨工具比较时按同一形态比，⛔ 不用文本管道取指纹（会改字节）。
