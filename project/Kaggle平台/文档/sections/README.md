## 边界

- 本目录**只放原文**：命名建议 `<比赛或页组>__<页名>.md`，一页一文件，⛔ 不把多页拼成一份「精华版」。

- ⛔ **不因为有了正文就当整页都读过**：引用具体条款前回到该节原文，写明节名或行号。
- 页面改版：新版另存一个文件并在表里加行，旧行保留并注明「已被取代」。
