# 现状页（人读）与 AI 材料

页面只写研究内容。主会话提供分析、结论、下一步和原始证据。每次正文交付必须实际派出 scribe 会话。

## 1 八节（研究口径）

| 节 | 内容 |
|---|---|
| 1 你的要求 | 真实用户要求、研究含义及来源 |
| 2 一句话现状 | 研究问题、目标和当前能说什么 |
| 3 最近实验 | 总量最多最近 3 轮，包含当前实验且当前优先。每块按假设 → 判据 → 设置 → 结果，附来源 |
| 4 已定 / 已否 / 待定 | 保留判断的条件、收益、代价和解释边界 |
| 5 本轮改了什么 | 新增、撤回、更正及证据链 |
| 6 这轮结论依赖的未验证前提 | 未验证条件、比较限制与缺件 |
| 7 证据在哪 | 原始产物及详细指纹的链接 |
| 8 下一步研究 | 尚未启动、能减少科学不确定性的研究动作 |

探索性实验写观察、条件和解释边界，不强制数字门槛。确认性实验保留有依据的门槛。没有实验时写「暂无实验，未起跑」和原因。尚未运行的计划不能写成结果。

## 2 人读页与机器材料

人读页不放机器周期表、心跳、租约、审计额度或登记流程。流程状态保存在实例工作区 `.autoresearch/state/process_status/`。AutoDL worker每次成功采集后对已登记专题更新此投影，不改STATUS正文。计划任务须按新机路径显式安装，clone不自动注册。缺库、缺表、缺专题目录或采集失败时保留unknown，不能伪造运行状态。

AI 工作材料必须由原始计划与结果投影生成，不手工维护第二份科学台账。两类投影都不能替代原始证据。

来源版本放在机器回执。记录页面 SHA256、来源清单及各来源 SHA256、实际写页会话和角色、生成时采用的事件截止。禁止用 mtime 证明来源新鲜。心跳不证明实验存活，也不证明正文已经更新。

## 3 更新与交付

起跑、重要阶段结果、停跑、被替代、最终结束均触发更新。普通心跳不触发正文重写。

`validate_status_page(text)` 检查研究八节、非空正文、最近轮数、四段顺序及来源标记。它不判断数字与结论是否正确。旧提取版页面使用显式 `legacy=True` 只读兼容，不追溯改写。

取消「需要你拍板」「正文覆盖版本」、十一格、周期机器块的必填要求。历史旧页可以保留这些字段，新页不要求它们。

回执必须声明实际写页者 `writer_role=scribe` 和 `writer_session`。声明不证明真实会话身份，可信验收还需宿主验证器。子会话不可用时保留材料与待更新状态，不能声称页面已经由 scribe 交付。

安全停机不等待文档通过。失败要保留证据、待办与恢复入口。

## 4 默认创建与旧专题补建

`workspace topic`从版本模板创建TOPIC、当日EVIDENCE与STATUS。生成页保留SCAFFOLD标记，表示待填骨架，不证明没有历史数据，也不作为已交付研究报告。scribe根据可追溯材料完成正文后删除标记，再走验收回执。

`workspace documents --workspace <工作区> --topic <专题>`只补缺失类别。已有证据页即不另造当天空页，所有已有文档保留实际字节。模板副本随分层初始化安装到框架templates目录，生成器使用其所在框架版本的模板，回执记录模板与结果哈希。

## 5 回传

先给结论与关键研究理由，再说缺什么证据。拒绝或取消也只讲关键研究理由。过程账留在机器回执。

## 6 接料检查：负责人先完成研究判断

交付前，负责人必须先给出**可核验的研究判断**，不只是素材。scribe 先做接料检查，再组织页面。

| 必须能定位 | 缺了怎么办 |
|---|---|
| 当前阶段、原假设、观察与解释边界 | 列缺项，返回负责人 |
| 假设怎么改的、为什么改（引哪条读数或哪次失败） | 列缺项，返回负责人 |
| 下一步、选择理由、适用的用户纠正 | 列缺项，返回负责人 |
| 已登记的负责人判断（`leader_conclusion`，带来源与定位） | 返回负责人登记；⛔ scribe 不补写 |

- 缺项时只返回**具体缺项**与要负责人回答的问题；可先更新可核验事实，并标明判断待补。⛔ 不替负责人推导假设、不代选下一轮、不补全理由。
- 结论强度、条件或下一步发生任何变化 ⇒ **返核**；scribe 不改这些。
- scribe 自己的新解释或下一步建议必须在回传中**单列**并交回负责人。未经负责人采纳并登记来源，⛔ 不写成页面上的结论或计划；采纳后由负责人写进既有专题材料或 `leader_conclusion`，scribe 再按决定写。
- 机器侧等价判据（⛔ 不另建手工台账）：`reporting.request()` 在缺负责人判断时把任务停在 `pending_owner`；`reporting.handoff_check()` 只读复述同一批 blocker；`ack` 在缺项时直接拒收。

⚠️ 接料检查只判材料齐不齐，**不构成**实验审批或安全停机条件；运行停止永远不等文档通过。
