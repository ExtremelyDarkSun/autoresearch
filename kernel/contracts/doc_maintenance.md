# 文档维护：分层、上限、滚动

> 一句话：**按「读的频次」分层，热件有硬上限，到线就滚成冷件，滚是搬运不是删除。**

---

## 1 十三条原则（P1–P13）

| # | 原则 | 一句话判据 |
|---|---|---|
| **P1** | 按**读的频次**分层，⛔ 不是按总大小 | 一份很大但一年读一次的不用切；要切的是「每次动它都得通读」的那份 |
| **P2** | 按**生命周期状态**切（未结案 / 已结案），⛔ 不是按主题 | 按主题切 ⇒ 想知道现状得读每一个主题 |
| **P3** | 冷件按**时间**切片（一天一份），⛔ 不是按主题 | 找某条先定位到哪天，再只读那一天 |
| **P4** | 热件必须有**硬上限**，到线就滚 | 没有上限的规则必然漂 |
| **P5** | 编号与节号**永不重用、永不重排**；冷件原样保留原号 | 删一条 = 标 `drop`，⛔ 不删块 |
| **P6** | 滚动 = **搬运 + 留痕**，⛔ 不是删除 | 冷件是证据，逐字不改；删除要用户同意 |
| **P7** | **双向指针** | 热件顶部写「已滚出到哪些冷件」；冷件顶部写「从哪份热件滚来 · 覆盖哪些编号 · 滚动时刻 · 滚动前热件 sha256」 |
| **P8** | 冷件必须有**索引**，且能按编号反查 | 没有索引的冷件等于丢失 |
| **P9** | 切割面只落在**已结案**上 | 「部分解决」「仍被引用」「有争议」的留在热件 |
| **P10** | 滚动必须在**没有其他写者**的窗口里做 | 并发滚动会丢别人的追加，而且不报错 |
| **P11** | 滚动前后各记一次**可核值**（字节数 + sha256），且算 hash 与最后一次写之间不许有别的写 | 做不到就别把 hash 写在同一份还会被写的文件里 |
| **P12** | 每条「必须滚」要么是**会红的闸**，要么在收工报告里显式列为「仍是纪律」 | 只写「应当定期滚动」等于不会滚 |
| **P13** | **渐进式披露**：先给当前答案，再给行动依据，最后按需读历史与原始证据 | 分层只决定阅读顺序和文件组织。相关现行文档仍须整份读，不能用摘要或节选代替正文 |

---

## 2 判定：一份文档该不该分层

依次问四个问题，任一为「是」就别分层：

1. 它一年只被读一两次？⇒ 不用切。
2. 它的读者是同一批人、且每次都读全份？⇒ 不用切。
3. 切开之后，想知道现状要读**每一个**主题？⇒ 那是按主题切，错。
4. 有「未结案」的条目混在里面？⇒ 先只切已结案那部分（P9）。

---

## 3 滚动怎么做（照做八步）

1. **停写**：确认没有其他写者（P10）。
2. **量**：记下热件字节数与 sha256（P11）。
3. **选面**：只挑**已结案**的节（P9）。
4. **搬**：原样搬进冷件（按日期命名），逐字不改（P6）。
5. **写头**：冷件顶部写来源热件 · 覆盖编号 · 滚动时刻 · 滚动前热件 sha256（P7）。
6. **建索引**：索引表加行 `编号 → 冷件文件名`（P8）。
7. **回写指针**：热件顶部写「已滚出到 X」（P7）。
8. **重登记**：`register_doc(...)` 记新的热件版本；`roll_cold(...)` 记这次滚动。
   `doc_status()` 会列出超上限的热件与缺索引的冷件。

---

## 4 机械判据（`governance`）

| 规矩 | 谁拒 |
|---|---|
| 热件必须给上限 | `register_doc(tier="hot")` 缺 `limit_bytes` ⇒ 抛错 |
| 超上限可见 | `doc_status()["hot_over_limit"]` + `problems` |
| 滚动基线必须对 | `roll_cold` 的 `hot_sha_before` ≠ 最近登记哈希 ⇒ 拒 |
| 冷件不能与热件同路径 | `roll_cold` 拒（那是覆盖不是搬运） |
| 冷件必须带索引 | `roll_cold` 要求 `index_path` 非空；`doc_status()["cold_missing_index"]` |
| 谁滚的、滚之前是什么 | `gov_doc_rolls` append-only 一行 |

---

## 5 仍是纪律

1. **「这次该不该滚」** 是人判断（P12 只要求你把它写成闸或列为纪律）。
2. **搬得对不对**：脚本不知道你搬走的是不是「已结案」。
3. **索引与冷件是否一致**：`doc_status` 只查索引路径非空，不查内容对不对。
